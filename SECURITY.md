# Seguridad

No adjuntes archivos confidenciales ni credenciales a issues públicos. Para una vulnerabilidad, usa la opción de reporte privado de GitHub si está disponible; de lo contrario, contacta al responsable mediante su perfil antes de compartir detalles explotables.

El código compartido se ofrece bajo MIT. La compilación local usa firma ad hoc y no está notarizada. El envío LAN actual usa HTTP temporal y requiere una red de confianza. No debe anunciarse como compatible con LocalSend o como cifrado.
